# Agent Security Dashboard

A review-ready React + TypeScript concept dashboard for monitoring autonomous agent risk posture. The interface uses Material Design 3 color tokens, rounded surfaces, tonal buttons, status chips, and responsive dashboard layouts.

## Features

- Fleet trust score and highest-risk agent summary
- Risk signal KPI cards
- Agent runtime posture table
- Live audit/safeguard event stream
- Active security controls strip
- Responsive Material Design 3-inspired UI

## Tech stack

- React
- TypeScript
- Vite
- CSS-only Material Design 3 styling

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run build
```
